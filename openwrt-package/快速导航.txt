💡 最快的方法：
==========================================

1. 访问 GitHub 仓库
2. 点击 Fork
3. 进入 Actions
4. 点击 Run workflow
5. 等待 20 分钟
6. 下载 IPK

详见：快速开始-GitHub版.md
