# APRX for OpenWrt - 快速开始

## 🚀 一键编译

如果你想快速编译 IPK 包，只需要运行：

```bash
cd /workspace/openwrt-package
./build-ipk.sh
```

这个脚本会自动：
1. 下载 OpenWrt 24.10.4 SDK (MT7621)
2. 配置编译环境
3. 编译 APRX IPK 包

## 📦 生成的文件

编译成功后，你会得到：
- `aprx_2.9-1_mipsel_24kc.ipk` - 主程序包

文件位置：`openwrt-sdk-*/bin/packages/mipsel_24kc/packages/`

## 📥 安装到路由器

### 方法 1: 通过 Web 界面
1. 下载生成的 IPK 文件
2. 登录 OpenWrt LuCI 界面
3. 进入 系统 -> 软件包
4. 点击 "上传软件包"
5. 选择 aprx IPK 文件并安装

### 方法 2: 通过命令行

```bash
# 1. 复制到路由器
scp aprx_*.ipk root@你的路由器IP:/tmp/

# 2. SSH 登录路由器
ssh root@你的路由器IP

# 3. 安装
opkg install /tmp/aprx_*.ipk

# 4. 编辑配置
vi /etc/aprx.conf

# 5. 启动服务
/etc/init.d/aprx start
/etc/init.d/aprx enable
```

## ⚙️ 基本配置

编辑 `/etc/aprx.conf`，至少需要修改：

```conf
# 你的呼号
mycall  BG1ABC-10

# 你的位置
myloc   lat 3950.00N lon 11620.00E

# APRS-IS 登录信息
<aprsis>
    login    BG1ABC-10
    passcode 你的密码   # 从 https://apps.magicbug.co.uk/passcode/ 获取
    server   asia.aprs2.net  14580
</aprsis>
```

更多配置示例请参考 `aprx/files/aprx.conf.example`

## 🔧 硬件连接

### USB 串口 TNC
```conf
<interface>
    serial-device /dev/ttyUSB0  9600 8n1  KISS
    callsign  BG1ABC-10
    tx-ok     true   # 如果需要发射功能
</interface>
```

### 网络 TNC (KISS over TCP)
```conf
<interface>
    tcp-device  192.168.1.100  8001  KISS
    callsign    BG1ABC-10
    tx-ok       false
</interface>
```

## 📊 查看状态

```bash
# 查看服务状态
/etc/init.d/aprx status

# 查看日志
logread | grep aprx

# 查看统计信息
aprx-stat

# 测试配置文件
aprx -f /etc/aprx.conf -t
```

## 🐛 常见问题

### 1. 串口设备找不到
```bash
# 查看所有串口设备
ls -l /dev/tty*

# 查看 USB 串口
ls -l /dev/ttyUSB*

# 安装 USB 串口驱动
opkg update
opkg install kmod-usb-serial kmod-usb-serial-pl2303
```

### 2. 服务无法启动
```bash
# 检查配置文件语法
aprx -f /etc/aprx.conf -t

# 手动运行查看错误
aprx -f /etc/aprx.conf -d -v
```

### 3. 无法连接 APRS-IS
- 检查网络连接
- 验证呼号和密码是否正确
- 尝试更换服务器 (rotate.aprs2.net, asia.aprs2.net 等)

## 💡 支持的功能

✅ RX-iGate (接收并转发到 APRS-IS)
✅ TX-iGate (从 APRS-IS 转发到无线电)
✅ 数字中继器 (Digipeater)
✅ 粘性数字中继器 (Viscous Digipeater)
✅ KISS TNC 支持
✅ 多串口/多 TNC 支持
✅ D-STAR D-PRS 支持
✅ 流量统计 (Erlang Monitor)
✅ 位置信标发送
